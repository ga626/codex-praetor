# Codex Praetor 0.14.0-alpha

## 本次交付

- 为真实任务评测补齐可审计的证据上下文：任务来源、连接方式、验收器身份与版本、完整时间线和人工介入次数。
- 只有来源明确的真实历史问题或真实用户请求，在 Codex `accepted` 后才可以写入能力画像；合同回归夹具、canary 和 marker 继续只能证明自身合同，不能冒充真实 worker 能力。
- 任务账本现在记录 worker 提交、启动、结束与验收时间，便于区分 worker、任务合同、验收器与环境问题。

## 用户可见边界

- 本版不新增任何 provider，也不把 Qoder 或 CodeBuddy 宣称为对某个任务族已经可用；真实能力仍须由独立 accepted 记录证明。
- Codex 仍负责拆解、授权、验收、整合和最终答复。外部 worker 只接收边界清楚的工作包。
- 不读取、输出、迁移认证资料或 provider 数据库，也不修改 provider 设置。
